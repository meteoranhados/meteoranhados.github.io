Como ler o calendário?

Temperatura média / Tmax / Tmin: a cor representa o valor absoluto daquele dia. Não é uma anomalia diária face a uma normal diária.

Precipitação: branco significa 0 mm; a intensidade azul aumenta com a quantidade observada.

Extremos: símbolos assinalam Tmax ≥30 °C, Tmax >35 °C, noite tropical, geada e precipitação >10/20/30 mm.

Dias cinzentos tracejados: não há registo diário; não são tratados como zero.
